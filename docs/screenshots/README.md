# Direktori Tangkapan Layar (Screenshots) WarungStock

Direktori ini dipersiapkan untuk menyimpan tangkapan layar antarmuka aplikasi WarungStock sebagai bukti pengujian dan dokumentasi penyerahan tugas UTS PMP.

## Daftar Tangkapan Layar yang Disiapkan

1. `01_login_screen.png` — Tampilan halaman Masuk (Login Screen).
2. `02_register_screen.png` — Tampilan halaman Pendaftaran Akun (Register Screen).
3. `03_home_inventory_screen.png` — Tampilan Beranda Manajemen Inventaris (Firestore CRUD & Dashboard).
4. `04_add_item_dialog.png` — Tampilan dialog form Tambah / Edit Barang.
5. `05_product_catalog_screen.png` — Tampilan Katalog Produk Grosir (DummyJSON REST API via Dio).
6. `06_product_detail_screen.png` — Tampilan Detail Produk Grosir beserta galeri dan harga diskon.

> **Catatan:** Letakkan file tangkapan layar asli aplikasi web yang berjalan di browser Chrome pada direktori ini untuk ditampilkan pada `README.md`.
